移动端固定下导航（SVG 图标）

本页用 font 目录里 iconfont 的 SVG 方案：本地 iconfont.js 会在页面里注入一段隐藏的 <svg><symbol> 精灵图， 图标换成矢量图形后写成 <svg class="chen_svg"><use xlink:href="#icon-shouye"></use></svg> 来引用。下导航依旧 position: fixed 贴在底部、width: 100% 占满屏宽， 四个导航项 flex: 1 1 0px 平分宽度，颜色由 fill: currentColor 跟随文字色。

SVG 写法说明

符号的 viewBox 是 0 0 1024 1024，所以缩放只改 CSS 宽高即可； fill: currentColor 让矢量图跟随 color，切换选中色不用换图。

提示：未检测到 <symbol> 精灵图，请确认 iconfont.js 已加载， 并且 <use xlink:href="#icon-名字"> 的名字与 font 目录中的图标一致。 

<!-- 1. 引入 font 目录里本地的 symbol 脚本，它会把精灵图插到 body 里 -->
<script src="./font/font_5244823_nkj1sa0pqh/iconfont.js"></script>

<!-- 2. 用 svg + use 引用具体图标（图标以矢量图形绘制，不再是字体） -->
<svg class="chen_svg" aria-hidden="true">
  <use xlink:href="#icon-shouye"></use>
</svg>

/* 3. 尺寸与颜色全部由 CSS 控制 */
.chen_svg {
  width: 24px;
  height: 24px;
  fill: currentColor;   /* 跟随父元素 color */
}
.chen_tab { flex: 1 1 0px; }   /* 四项平分屏宽 */
.chen_tabbar { position: fixed; left: 0px; right: 0px; bottom: 0px; width: 100%; }

导航项上的两种提示

数字徽章贴在图标右上角，用于显示具体数量（超过 99 写成 99+）； 红点放在导航项自己的右上角，表示“有新内容”而不透露数量，两者可以同时出现。

数字徽章 .chen_badge

绝对定位在图标盒子右上角 right: -10px、top: -6px， 红底白字圆角胶囊加两像素白描边，数字再多也只向内撑开、不会挤压图标。

红点 .chen_dot

八个像素圆点固定在导航项右上角，配合 @keyframes chen_blink 做缩放呼吸动画，提示有新内容但不必显示数字。

SVG 比字体图标更灵活

矢量图形可以直接改 fill、加描边与滤镜，选中态还能做形变动画； 字体图标只能改字号和颜色。

自适应与安全区

四项平分 100% 屏宽，窄屏靠媒体查询缩小字号；容器 padding-bottom: env(safe-area-inset-bottom) 避开 iPhone 小横条。
