CSS 变量（自定义属性）

CSS 变量以 -- 开头定义，用 var() 引用， 例如 --chen_blue: #4ca9d9; 之后即可写 color: var(--chen_blue);。 它遵循 CSS 的层叠与继承规则：在 :root 定义即为全局变量， 在某个选择器内定义则只作用于该元素及其后代。改一处变量，整站引用它的地方都会同步更新， 这正是本页由 陈卓然 制作的主题切换效果的原理。

变量驱动的主题切换（纯 CSS）

当前主题由 CSS 变量控制

点击上方的按钮，只是改变了 --chen_tbg、--chen_tfg、 --chen_taccent 这几个变量，下方的背景色、文字色与按钮色便同时切换， 页面没有使用任何脚本。

主要按钮

变量作用域变化时，过渡动画会平滑衔接。

变量的常见用法

基本定义与引用

var(--chen_blue)

:root { --chen_blue: #4ca9d9; } 定义后，任意位置都可用 var(--chen_blue) 取用。

局部作用域覆盖

父级 子级

在子元素重新定义同名变量，只影响该子树，父级不受影响。

回退值 fallback

缺省时的橙黄色

var(--chen_not_defined, #ffc46b)：变量不存在时使用逗号后的回退值。

与长度单位配合

变量可保存任意长度值，如 --chen_size: 54px;，统一调整尺寸。

CSS 变量的优势

--var一处修改，全局生效
把颜色、间距、圆角抽成变量后，只需改动定义处，所有引用点自动更新，便于统一维护。
var()运行时可变
变量可被媒体查询、:hover、:checked 等状态重新赋值，实现动态换肤与响应式调整。
inherit遵守层叠继承
变量像普通属性一样继承，可以利用作用域写出层次清晰的样式结构。
