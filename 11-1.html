CSS 长度单位

Web 前端中长度值由「数字 + 单位」组成，例如 10px、2rem。 单位可分为绝对单位（px、cm、mm、in、pt、pc） 与相对单位（%、em、rem、vw、vh、vmin、vmax、ch、ex）。 下面的方块展示了每个单位的真实渲染尺寸。

单位对照表

px · 像素

绝对单位，屏幕上的一个像素点，最常用的固定尺寸。

cm · 厘米

绝对单位，1cm = 37.8px，常用于打印样式。

mm · 毫米

绝对单位，1mm = 0.1cm ≈ 3.78px。

in · 英寸

绝对单位，1in = 2.54cm = 96px。

pt · 磅

绝对单位，1pt = 1/72in ≈ 1.33px，常用于字体。

pc · 派卡

绝对单位，1pc = 12pt = 1/6in，印刷排版常用。

% · 百分比

相对单位，相对于父元素的对应尺寸。

em · 相对字体

相对当前元素字体大小，若字体为 16px，则 1em = 16px。

rem · 根字体

相对根元素（html）的字体大小，本例根字号为 16px。

vw · 视口宽度

相对视口宽度，1vw = 视口宽度的 1%。

vh · 视口高度

相对视口高度，1vh = 视口高度的 1%。

vmin / vmax

相对视口较小 / 较大的一边，1vmin 取宽高中较小值的 1%。

ch · 字符宽度

相对「0」字形的宽度，适合限制等宽字符数量。

ex · 小写高度

相对当前字体小写字母 x 的高度，较少使用。

fr · 网格分数

Grid 专用单位，按剩余空间的比例分配列宽，1fr : 2fr : 1fr。

CSS3 3D 动画演示

px绝对长度
px 不随字体与视口变化，大小恒定，适合边框、阴影等细节。
rem相对长度
rem 只参照根元素字号，页面全局缩放时最稳定，推荐用于布局尺寸。
vw / vh视口单位
vw、vh 随浏览器窗口变化，适合全屏区块与响应式排版。
