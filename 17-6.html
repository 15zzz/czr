包饺子流程（Promise / async-await）

流程：买原料 → 取原料 → [和面 && 和馅 并行] → 包饺子 → 吃饺子。 每个步骤用 setTimeout 模拟耗时，通过 Promise 包装，再用 async/await 编排顺序与并行。

核心代码（async/await + Promise.all）

// 把 setTimeout 包装成 Promise
function czr_delay(czr_msg, czr_ms) {
    return new Promise(function (resolve) {
        setTimeout(function () { resolve(czr_msg); }, czr_ms);
    });
}

async function czr_run() {
    await czr_delay('买原料', 6000);
    await czr_delay('取原料', 2000);
    // 并行：和面(4s) 和 和馅(5s)，总耗时取最大值 5s
    await Promise.all([
        czr_delay('和面', 4000),
        czr_delay('和馅', 5000)
    ]);
    await czr_delay('包饺子', 5000);
    await czr_delay('吃饺子', 3000);
}
