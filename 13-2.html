Lucide SVG 图标

Lucide 把每个图标直接做成一段 SVG 矢量代码：一个 <svg> 标签，里面是 <path>、<circle> 等图形元素， 用 stroke="currentColor" 描边绘制。页面里先写占位元素 <i data-lucide="house"></i>，再由本地 cdn/lucide/lucide.min.js 调用 lucide.createIcons() 把它替换成真正的 <svg> 元素——所以图标不再是“字符”， 而是可以直接控制 width、height、stroke-width 的图形。

SVG 的尺寸：width / height 属性或 CSS

SVG 是图形，直接改盒子尺寸即可，常用单位 16px、28px、1.5rem、2em。

SVG 的颜色：stroke 使用 currentColor

图标描边写的是 stroke="currentColor"，会跟随父元素的 color，因此改颜色不用换图。

SVG 的线宽：stroke-width

stroke-width 是 SVG 自带的表现属性，可直接用 CSS 覆盖，1 表示细线，4 表示粗线。

stroke-width: 1
stroke-width: 2
stroke-width: 3
stroke-width: 4

为什么用 SVG 图标

不依赖字体文件

SVG 就是普通标签，没有 @font-face、没有字体加载失败变方块的问题，浏览器拿到 <svg> 即可绘制。

属性可精确控制

width、height、stroke-width、stroke-linecap 都能按需改写，还能用 CSS 伪元素继续装饰。

颜色跟随文字

stroke="currentColor" 让描边自动取父级颜色，深底反白、悬停变色都只需改 color。

可内联可复用

内联后可以用 <use> 复用、加滤镜、做形变动画，也能直接在设计软件里编辑路径。

字体图标 vs SVG 图标（悬停翻转）

字体图标Font Awesome · 悬停翻转
图标是字体里的字符，靠 content 编码取出，改 font-size 与 color 即可，一个字体文件包含成千上万个图标。
SVG 图标Lucide · 悬停翻转
图标是一段图形标签，width/height/stroke-width 全部可控，只取用需要的那几个，不用下载整套字体。
加载开销悬停翻转
字体要下载整个 woff2（本页 solid 字体 156KB），SVG 只有几百字节的路径数据，按需内联更轻。
可定制性悬停翻转
SVG 可改路径、加渐变与动画、按主题换色；字体图标则受字符编码限制，样式自由度较低。
