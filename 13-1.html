Font Awesome 字体图标

字体图标就是把图标做成一套字体文件：Font Awesome 用 @font-face 加载本地的 fa-solid-900.woff2，再借助伪元素写成 .fa-house::before { content: "\f015"; }，让浏览器到字体里取出对应字形画出来。 所以图标本质上是“文字”，可以用 font-size、color 随意缩放上色， 放大后依然清晰不模糊。本页所有 CSS 与字体文件已下载到本地 cdn/fontawesome/ 目录，离线也能正常显示。

代码与原理

<link rel="stylesheet" href="./cdn/fontawesome/css/all.min.css">

<!-- 图标就是一个空元素，字形由 CSS 伪元素提供 -->
<i class="fa-solid fa-house"></i>
<i class="fa-regular fa-heart"></i>
<i class="fa-brands fa-github"></i>

/* all.min.css 里对每个图标做的事（节选） */
.fa-house::before { content: "\f015"; }
.fa-solid, .fa-free { font-weight: 900; }

/* 像文字一样调大小、调颜色 */
.my-icon { font-size: 48px; color: #145a8d; }

字体图标的特点（悬停翻转看背面）

字形悬停翻转
一个图标 = 字体里的一个字符，靠 ::before 的 content 编码取出，天然继承文字的字号、颜色、行高。
无损缩放悬停翻转
矢量字形放大到 100px 也不失真，改 font-size 即可，还能配合 -webkit-text-stroke 描边。
易于上色悬停翻转
因为是文字，直接写 color 就换色，还能做渐变文字、阴影、透明度等排版效果。
依赖字体文件悬停翻转
必须加载 .woff2/.ttf 字体，字体没加载到时会显示成小方块，这也是本页把字体放进本地 cdn 目录的原因。
