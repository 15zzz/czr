JavaScript 两种定时器

setTimeout() 在指定延迟后执行一次回调；setInterval() 每隔指定时间循环执行回调。 分别可用 clearTimeout() 和 clearInterval() 取消。

setTimeout 一次性
延迟指定毫秒后执行一次回调函数，适合定时任务、延迟加载、消息自动消失等。
3
点击「开始倒计时」，3 秒后触发回调
日志区：暂无
var czr_t = setTimeout(function () { console.log('3 秒到了，执行一次'); }, 3000); // 取消：clearTimeout(czr_t);
setInterval 循环
每隔指定毫秒重复执行回调函数，适合轮询、计时器、动画帧、实时数据刷新等。
0
点击「开始」，每秒 +1，最多到 10
日志区：暂无
var czr_i = 0; var czr_t = setInterval(function () { czr_i++; console.log('第 ' + czr_i + ' 次'); if (czr_i >= 10) clearInterval(czr_t); }, 1000);
