Grid 网格布局

CSS Grid 通过 display: grid 把容器划分成行列， 再用 grid-template-areas 为每个网格区域命名， 子元素只写 grid-area: 名称 即可自动落位。 本页使用的正是 'a b b' / 'c b b' / 'c d e' / 'c d f' 这一套区域布局。

区域效果预览

a第 1 行第 1 列
b跨 2 行 2 列的 2×2 大区块
c纵跨 4 行的左侧竖条
d纵跨 2 行
e单格

对应的 CSS 代码

.chen_grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: repeat(4, 110px);
    grid-template-areas:
        "a b b"
        "c b b"
        "c d e"
        "c d f";
    gap: 14px;
}

.chen_a { grid-area: a; }
.chen_b { grid-area: b; }
.chen_c { grid-area: c; }
.chen_d { grid-area: d; }
.chen_e { grid-area: e; }
.chen_f { grid-area: f; }

要点提示

areas命名区域
相同名称的相邻单元格会合并成一个区域，因此 b 会自动变成 2×2、c 会纵跨 4 行。
fr弹性列宽
repeat(3, 1fr) 表示三列平分剩余空间，改动容器宽度时各列等比缩放。
gap行列间距
gap 统一设置行与列之间的空隙，比逐个 margin 更直观，也不会破坏区域合并。
