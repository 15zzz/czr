JavaScript 数组方法大全

陈卓然 · 共 20 个常用数组方法，按类别分组。
红色标签 = 会修改原数组  |  蓝色标签 = 返回新数组（原数组不变）

📦 演示用原始数组：czr_arr = [1, 2, 3, 4, 5]

12345

一、增删元素

push()修改原数组

在末尾添加元素，返回新长度

czr_arr.push(6);
// → arr 变为 [1,2,3,4,5,6]
结果

pop()修改原数组

删除末尾元素，返回被删值

czr_arr.pop();
// → 返回 5，arr 变为 [1,2,3,4]
结果

unshift()修改原数组

在开头添加元素，返回新长度

czr_arr.unshift(0);
// → arr 变为 [0,1,2,3,4,5]
结果

shift()修改原数组

删除开头元素，返回被删值

czr_arr.shift();
// → 返回 1，arr 变为 [2,3,4,5]
结果

splice()修改原数组

从指定位置删除/替换/插入元素

czr_arr.splice(2, 1, 99);
// → 从下标2删1个，插入99
结果

slice()返回新数组

截取子数组，原数组不变

czr_arr.slice(1, 4);
// → 下标 1,2,3 的元素
结果

concat()返回新数组

合并数组，原数组不变

czr_arr.concat([6, 7]);
// → [1,2,3,4,5,6,7]
结果

二、遍历 / 变换

forEach()不返回值

遍历执行回调，常用于打印或副作用操作

czr_arr.forEach((v,i) =>
  console.log(i, v)
);
结果

map()返回新数组

对每个元素做变换，返回新数组

czr_arr.map(v => v * 2);
// → [2, 4, 6, 8, 10]
结果

filter()返回新数组

筛选满足条件的元素

czr_arr.filter(v => v > 2);
// → [3, 4, 5]
结果

reduce()返回单值

累计计算，返回最终值

czr_arr.reduce((a, b) => a + b, 0);
// → 1 + 2 + 3 + 4 + 5 = 15
结果

三、查找 / 判断

indexOf()

返回元素下标，找不到返回 -1

czr_arr.indexOf(3);  // → 2
czr_arr.indexOf(99); // → -1
结果

includes()

是否包含某元素，返回 true/false

czr_arr.includes(3);  // → true
czr_arr.includes(99); // → false
结果

find()

找到第一个满足条件的元素值

czr_arr.find(v => v > 3);
// → 4（第一个大于3的数）
结果

findIndex()

找到第一个满足条件的下标

czr_arr.findIndex(v => v > 3);
// → 3（下标为3）
结果

some()

是否"存在"满足条件的元素

czr_arr.some(v => v > 4);
// → true（5 满足）
结果

every()

是否"全部"满足条件

czr_arr.every(v => v > 0);
// → true（全是正数）
结果

四、排序 / 转换

sort()修改原数组

原地排序，数值排序要传比较函数

[3,1,4,2,5].sort((a,b)=>a-b);
// → [1,2,3,4,5]
结果

reverse()修改原数组

原地反转数组顺序

[1,2,3,4,5].reverse();
// → [5,4,3,2,1]
结果

join()返回字符串

用分隔符把元素拼成字符串

czr_arr.join(' - ');
// → "1 - 2 - 3 - 4 - 5"
结果

toString()返回字符串

默认用逗号拼接

czr_arr.toString();
// → "1,2,3,4,5"
结果
