JavaScript 对象 & 字符串

陈卓然 · 对象（Object）与字符串（String）常用方法，点击「▶ 运行」实时查看结果

📦 演示用数据

var czr_person = { name: '陈卓然', age: 20, major: '高级网页设计' };
var czr_str    = 'Hello 陈卓然 1012';

一、对象（Object）常用方法

Object.keys(obj)

返回对象所有键名的数组

Object.keys(czr_person);
// → ['name', 'age', 'major']
结果

Object.values(obj)

返回对象所有值的数组

Object.values(czr_person);
// → ['陈卓然', 20, '高级网页设计']
结果

Object.entries(obj)

返回键值对数组

Object.entries(czr_person);
// → [['name','陈卓然'],['age',20],['major','高级网页设计']]
结果

Object.assign({}, obj)拷贝

浅拷贝对象（合并属性）

var czr_copy =
  Object.assign({}, czr_person);
czr_copy.age = 99;
// czr_person.age 不受影响
结果

obj.hasOwnProperty(k)

检查对象是否拥有某键

czr_person.hasOwnProperty('name'); // true
czr_person.hasOwnProperty('addr'); // false
结果

delete obj[key]修改

删除对象的某个属性

delete czr_person.age;
// czr_person 不再有 age 键
结果

for (let k in obj)

遍历对象所有可枚举属性

for (let k in czr_person) {
  // k 依次为 name, age, major
}
结果

二、字符串（String）常用方法

.length属性

获取字符串长度

czr_str.length;
// → 20（每个中文算 1 个长度）
结果

.toUpperCase()

全部转大写

'hello'.toUpperCase();
// → 'HELLO'
结果

.toLowerCase()

全部转小写

'HELLO'.toLowerCase();
// → 'hello'
结果

.indexOf(x)

查找子串位置，找不到返回 -1

czr_str.indexOf('陈');   // → 6
czr_str.indexOf('X');   // → -1
结果

.includes(x)

是否包含某子串

czr_str.includes('1012'); // true
czr_str.includes('9999'); // false
结果

.slice(s, e)

截取子串（含头不含尾）

czr_str.slice(6, 9);
// → '陈卓然'
结果

.substring(a, b)

截取子串（自动交换负值）

czr_str.substring(6, 9);
// → '陈卓然'，等价于 slice(6,9)
结果

.replace(a, b)支持正则

替换第一个匹配

czr_str.replace('Hello', 'Hi');
// → 'Hi 陈卓然 1012'
结果

.split(sep)

按分隔符拆分为数组

czr_str.split(' ');
// → ['Hello', '陈卓然', '1012']
结果

.trim()

去掉首尾空格

'  陈卓然  '.trim();
// → '陈卓然'
结果

.startsWith(x)

是否以某子串开头

czr_str.startsWith('Hello'); // true
czr_str.startsWith('Hi');    // false
结果

.endsWith(x)

是否以某子串结尾

czr_str.endsWith('1012'); // true
czr_str.endsWith('zzz');  // false
结果

.charAt(i) / [i]

获取指定下标字符

czr_str.charAt(6); // → '陈'
czr_str[6];        // → '陈'（更现代）
结果

.repeat(n)

重复拼接 n 次

czr_str.slice(6, 9).repeat(3);
// → '陈卓然陈卓然陈卓然'
结果
